## 🚀 Quick Start

### Local Development
1. Open `index.html` in a web browser
2. No build process required - it's a static site

### Deploy to Vercel

1. **Push to GitHub**
   ```bash
   git add .
   git commit -m "Initial portfolio commit"
   git push
   ```

2. **Connect to Vercel**
   - Go to [vercel.com](https://vercel.com)
   - Sign up / Log in
   - Click "New Project"
   - Import your GitHub repository
   - Click "Deploy"

3. **Get Live URL**
   - Vercel automatically provides your live URL
   - Example: `https://eyasu-portfolio.vercel.app`
